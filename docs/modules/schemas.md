# `schemas`

Zod is the source of truth for every data shape in ClipEngine. Repos
parse on read, routes validate on write, the engine takes typed
configs only. Nothing crosses a boundary as `unknown`.

## Files

- `preset.ts` — `PresetSchema` (versioned via `PRESET_SCHEMA_VERSION`
  + `migratePreset()`). `DEFAULT_LONGFORM_PRESET` and
  `DEFAULT_SHORTFORM_PRESET` are the seeders.
- `source.ts` — `SourceSchema` discriminated union (`upload`,
  `youtube_vod`, `youtube_live`).
- `run.ts` — run state machine, error codes, log + artifact shapes,
  and the on-disk pipeline outputs (`TranscriptDoc`, `ClipItem`,
  `CutPlan`).
- `settings.ts` — every per-user setting (`LlmSettings`,
  `TranscriptionSettings`, `SearchSettings`, `WorkerSettings`,
  `OnboardingState`) plus the `SETTING_SCHEMAS` lookup table that
  the SettingsRepo and routes use.
- `api.ts` — HTTP request / response shapes (registration body,
  onboarding test inputs, error envelope).

## Versioning

`PRESET_SCHEMA_VERSION` starts at `1`. When a future change requires
a non-additive update:

1. Bump the version.
2. Add a branch in `migratePreset()` that maps the old shape to the
   new one.
3. The importer keeps loading old exports forever.

Run schemas (transcripts, cut plans) are not versioned because they
never leave the install — they're regenerated by the engine on every
run.

## Conventions

- Every schema exports both the Zod schema and the inferred type
  (`PresetSchema` + `Preset`).
- Hex colors are `#RRGGBB` only (no alpha) because the only consumer
  is libass, which carries alpha elsewhere.
- Discriminated unions use `z.discriminatedUnion('type', ...)`. The
  `Source` and `TranscriptionSettings` use this pattern.
- `null` always means "intentionally absent". `undefined` shows up
  in TypeScript types but never in stored JSON.

## Tests

`packages/schemas/tests/` covers the validation rules: even
dimensions, ordered duration bounds, password match in the register
body, provider-specific required fields (e.g. `base_url` for
`openai_compatible`). 23 cases total.
