# API overview

ClipEngine ships a JSON-over-HTTP API at `/api/*`, plus a Server-Sent
Events stream for live run progress. Same-origin in production
(rewritten through `/api-engine/*` by the web app); cross-origin
requests honor the `CORS_ORIGINS` env var.

## Authentication

Every route except `/health`, `/api/registration-status`, and the
`/api/auth/*` family requires a valid Better Auth session cookie.
Cookies are set automatically by `/sign-up/email` and
`/sign-in/username` and forwarded by the Next.js `/api-engine` proxy.

Programmatic clients should grab the cookie from a sign-in response
and forward it on subsequent requests.

## Error envelope

Every non-2xx response uses the same shape:

```json
{
  "error": {
    "code": "http_error",
    "message": "human-readable detail",
    "path": ["optional", "field", "for", "validation"]
  }
}
```

Stable codes today: `http_error` for thrown `HTTPException`s,
`internal` for everything else. The HTTP status line carries the
real meaning (400 / 401 / 404 / 413 / 500).

## Request id

Every response carries an `x-request-id` header. Clients that send
their own header keep their value (truncated to 128 chars); otherwise
the server generates a UUID. Use it for log correlation.

## Endpoints

| Path | Methods | Purpose |
|---|---|---|
| `/health` | GET | Liveness probe. |
| `/api/registration-status` | GET | First-run gate. |
| `/api/auth/*` | varies | Better Auth (sign-up / sign-in / session). |
| `/api/settings` | GET, PATCH /:key | Per-user settings KV. |
| `/api/onboarding/state` | GET | Current onboarding step. |
| `/api/onboarding/test/{transcription,llm,search}` | POST | Live "Test connection" probes. |
| `/api/onboarding/complete` | POST | Mark onboarding done. |
| `/api/presets` | GET, POST | List, create. |
| `/api/presets/:id` | GET, PATCH, DELETE | Single preset. |
| `/api/presets/:id/export` | GET | Download preset JSON. |
| `/api/presets/import` | POST | Import preset JSON (validated + migrated). |
| `/api/logos` | GET, POST | List, multipart upload. |
| `/api/logos/:id` | DELETE | Remove a logo. |
| `/api/sources/uploads` | POST | Start a chunked upload. |
| `/api/sources/uploads/:id/chunks` | POST | Append a chunk. |
| `/api/sources/uploads/:id/cancel` | POST | Drop a half-finished upload. |
| `/api/sources/uploads/:id` | GET | Current upload state (resumability). |
| `/api/sources/youtube/probe` | POST | Soft-validate a YouTube URL. |
| `/api/runs` | GET, POST | List, create. |
| `/api/runs/:id` | GET | Single run. |
| `/api/runs/:id/logs` | GET | Run log lines. |
| `/api/runs/:id/artifacts` | GET | Files produced. |
| `/api/runs/:id/cancel` | POST | Cooperative cancel. |
| `/api/runs/:id/live/stop` | POST | Stop YouTube live capture. |
| `/api/runs/:id/stream` | GET (SSE) | Live progress stream. |

## OpenAPI

A formal OpenAPI document lands in [`docs/api/openapi.json`](openapi.json)
when generated by `pnpm docs:openapi`. The script wraps every route
with the matching Zod schema; until it runs, this page is the source
of truth.
